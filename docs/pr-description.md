# 셋업 앱 중앙 버전 관리 웹/API (LETMEUP-1221)

셋업 렛미업·클래스업 앱의 릴리스를 서비스와 stable/beta별로 확인하고 운영자가
검증한 전체 기본 목표·단말 지정·안정화 버전을 저장하는 Next.js 앱을 추가한다.
실제 파일 검증 뒤에만 목표를 지정하며 보고가 없는 설치 상태는 미보고로 표시한다.

외부 영구 JSON의 원자 교체·쓰기 직렬화·revision 충돌·손상 보호, 서명된 webhook의
중복/재처리와 20분 대조, 인증된 단말별 작은 목표 JSON/ETag를 제공한다.
웹·API·수집기는 단일 Node 프로세스와 PM2 fork로 운영한다.

검증: build/typecheck/lint, 저장소/API 테스트, 로컬 HTTP 10,000건 오류 0건.
실제 릴리스 결과는 docs/validation.md. 로컬 부하를 운영 용량으로 주장하지 않는다.

후속: HttpTargetSource 인증·304·폴링/백오프/재연결, 단말 등록/보고, 다른 앱과
런처 자체 업데이트, 마지막 정상 설치 파일/APP_READY 복구 연동.
운영 배포·지점 목표 변경·기존 공개 릴리스 변경·main 머지는 수행하지 않는다.
